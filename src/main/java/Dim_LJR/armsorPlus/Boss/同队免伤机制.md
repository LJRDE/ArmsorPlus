# BOSS 同队免伤机制

同一 BOSS 由多个实体组成（如双骑士 + 双坐骑、烈焰人 + 岩浆怪 + 小弟）时，
它们之间原本可能互相误伤（骷髅的箭射中僵尸、烈焰人的火焰弹炸到岩浆怪）。
该机制在 `BossMenu` 中统一拦截，**取消同一 BOSS 实体之间的伤害**，同时**不影响玩家攻击它们**。

## 核心实现

### 数据结构
```java
// 同队实体(骑士/坐骑/小弟等未注册为部位但属于本BOSS的实体) -> BOSS类型
private static final Map<UUID, BossType> bossFriendlies = new HashMap<>();
```

### 注册 API
```java
BossMenu.registerFriendlyEntity(BossType type, Entity entity);
```
由各 BOSS 在召唤时把"未被注册为主实体/身体部位"的同队实体加入，例如：
- 铁骑双雄：僵尸骑士、骷髅射手（战马/毒蛛已分别注册为主实体/身体部位，无需重复）。
- 熔岩双王：烈焰人小弟（烈焰人本体为主实体、岩浆怪为身体部位，无需重复）。

### 综合查询
```java
private static BossType lookupBossType(UUID id);
```
查找顺序：**身体部位(BOSS_BODY_PARTS) → 核心部位(BOSS_CORE_PARTS) → 主实体(bossEntities) → 同队实体(bossFriendlies)`。

### 伤害拦截
`onBossBodyPartDamage`（LOWEST 优先级）顶部：
1. 解析受伤实体 `damaged` 的 BOSS 类型；
2. 解析伤害来源（若是投射物则取发射者 `shooter`）的 BOSS 类型；
3. 两者**属于同一 BOSS** → `event.setCancelled(true)` 并返回。

玩家不是 BOSS 实体（`lookupBossType` 返回 null），因此玩家打 BOSS、BOSS 打玩家均不受影响。

### 清理
`BossMenu.unregisterBoss(type)` 会通过
```java
bossFriendlies.entrySet().removeIf(e -> e.getValue() == type);
```
一次性清除该 BOSS 的全部同队实体记录（BOSS 死亡/消失时自动完成）。

## 已启用该机制的 BOSS

| BOSS | 参与互免的实体 |
| --- | --- |
| 铁骑双雄 (DesertCamelBoss) | 僵尸骑士、骷髅射手、僵尸战马、毒蛛 |
| 熔岩双王 (LavaDuoBoss) | 烈焰人、岩浆史莱姆王、烈焰人小弟 |

## 注意事项
- 同队实体仍受**原生血量/AI** 驱动，玩家可以正常攻击击杀它们（不会命中免伤判断）。
- 新增双实体/多实体 BOSS 时，把"未被追踪的成员实体"用 `registerFriendlyEntity` 注册即可获得同队免伤。
- 若同一 BOSS 的两个实体需要**互相造成伤害**（例如故意设计的自伤技能），不要把它们注册为同队实体。
