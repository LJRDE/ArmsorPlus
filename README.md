# ArmsorPlus —— Minecraft 武器装备强化插件

为 Minecraft 1.21+ Paper 服务器带来 RPG 化的装备、附魔与 BOSS 战斗体验。

## 功能概述

- **18 种自定义附魔** —— 基于 PDC 存储，独立于原版附魔系统
- **强化石系统** —— 拖动强化石到装备上提升属性
- **魔法球抽奖** —— 使用经验值兑换，右键抽取随机附魔书
- **7 件魔法武器** —— 每件拥有独特机制和特效
- **食物/药品** —— 回春散（4 品级）、止血绷带、压缩饼干
- **3 个 BOSS** —— 急冻树、爆炎树、史莱姆王，含元素反应机制
- **公海世界** —— 自定义地图 + 宝藏抽奖系统
- **GUI 菜单** —— 向导书一键打开，支持合成配方查询
- **玩家设置** —— 附魔通知开关、管理员模式

## 环境要求

| 项目 | 要求 |
|------|------|
| 服务端 | Paper 1.21+（兼容至 1.13） |
| Java | 21+ |
| 前置插件 | 无 |

## 快速开始

1. 下载 `ArmsorPlus.jar` 放入 `plugins/` 目录
2. 重启服务端
3. 用圆石合成**高级附魔向导书**，右键打开主菜单
4. OP 玩家可使用 `/ArmsorPlus help` 查看所有管理命令

## 自定义附魔

所有附魔通过 PDC 存储，**拖动附魔书到装备上**即可使用，不占用原版附魔槽位。

### 装备附魔

| 附魔 | 适用装备 | 效果 |
|------|----------|------|
| 闪避 | 靴子 | 概率闪避攻击（对玩家 15%/级，对生物 20%/级） |
| 影避 | 靴子 | 概率闪避**所有类型**伤害（6%/级） |
| 涟漪 | 靴子 | 受到伤害时回复生命值（每级 +1） |
| 格挡 | 头盔 | 按伤害比例减免（高伤害格挡更多） |
| 生命提升 | 胸甲 | 每级 +5 最大生命值 |
| 涤魂 | 胸甲 | 周期性免疫魔法伤害（冷却随等级缩短） |
| 复仇 | 胸甲 | 概率反弹 50% 伤害（20%/级） |
| 幸存 | 护腿 | 受到致命伤害时概率复活（10%/级） |

### 武器附魔

| 附魔 | 适用装备 | 效果 |
|------|----------|------|
| 血祭 | 剑 | 概率消耗 15 HP 造成 2~(等级+1) 倍伤害 |
| 双重打击 | 武器 | 概率造成双倍伤害（20%/级） |
| 吸血 | 武器 | 攻击吸取生命值（每级 1.5 点） |
| 凋零 | 武器 | 攻击附加凋零效果（每级 5 秒） |
| 寒冻 | 武器 | 攻击附加缓慢效果（每级 1 秒） |
| 饥荒 | 武器 | 攻击附加饥饿效果 |
| 疾刺 | 三叉戟 | 右键获得速度提升（每级 +10%） |

### 远程附魔

| 附魔 | 适用装备 | 效果 |
|------|----------|------|
| 蓄爆 | 弓/弩 | 箭矢替换为烟花火箭，命中后爆炸造成范围伤害 |
| 弹道 | 弓/弩 | 箭速每级翻倍，伤害同步提升 |

## 魔法球

使用经验值在菜单商店中兑换，右键使用可随机获得附魔书。

| 等级 | 需求经验 | 保底附魔书 |
|------|----------|-----------|
| 寻常 | 30 级 | 1 本 |
| 稀罕 | 50 级 | 2 本 |
| 史诗 | 70 级 | 3 本 |
| 传奇 | 150 级 | 4 本 |

每层保底独立抽取，每次抽取 10% 概率获得对应附魔书（随机等级）。

## BOSS 系统

在主菜单中进入 BOSS 清单召唤，**需先在 BOSS 世界**中召唤。

| BOSS | 生命值 | 特性 |
|------|--------|------|
| 急冻树 | 750 | 冰元素 BOSS，树形结构（躯干+核心），火/雷元素触发双倍伤害反应 |
| 爆炎树 | 750 | 火元素 BOSS，树形结构（躯干+核心），雷/冰元素触发双倍伤害反应 |
| 史莱姆王 | 750 | 巨型史莱姆持有满级重锤，跳跃粉碎攻击，半血分裂激怒 |

- 攻击**躯干部位**：3 倍武器伤害
- 攻击**核心部位**：15 倍武器伤害
- 元素反应命中核心有 50% 概率暴露 BOSS 弱点

## 公海世界（测试版）

独立的世界地图，含宝藏抽奖和守护者挑战。

**配置（config.yml）：**

```yaml
SpawnOpenSea: false          # 是否启用公海世界
AutoResetOpenSeaMap: false   # 是否每次重启自动重置地图
OpenSeaName: "OpenSea"       # 世界文件夹名
MapZipName: "OpenSea.zip"    # 地图压缩包名
```

如需自定义地图，替换 jar 内的 `OpenSea.zip`，或修改 `MapZipName` 指向你的压缩包。

## 指令参考

所有指令需要 `ArmsorPlus.op` 权限（默认 OP）。

| 指令 | 说明 |
|------|------|
| `/ArmsorPlus help` | 查看指令帮助 |
| `/ArmsorPlus info` | 查看插件信息 |
| `/ArmsorPlus guide` | 获得高级附魔向导书 |
| `/ArmsorPlus give <物品> [数量] [等级]` | 给予物品 |
| `/ArmsorPlus getEnchantmentLevel <附魔>` | 查看手持物品附魔等级 |
| `/ArmsorPlus removeEnchant <附魔\|all>` | 移除手持物品附魔 |
| `/ArmsorPlus reloadmap` | 重载公海地图 |
| `/ArmsorPlus spawn` | 公海传送（开发中） |

### 可用物品名

`Arms_I`, `Arms_II`, `Armor_I`, `Armor_II`, `Bow_I`, `DiamondPlus`, `BasicStone`, `GuideBook`, `MagicBal_I` ~ `MagicBal_IV`, `Blood_Sword`, `Iron_Epee`, `Dagger`, `ThrowingAxe`, `SkeletonScepter`, `FrostBow`, `FlameHalberd`, `RejuvenationPowder`, `HemostaticBandage`, `CompressedBiscuit`, 以及各附魔书（如 `Dodge_EnchantedBook`）
