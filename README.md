# ArmsorPlus —— Minecraft 武器装备强化插件

为 Minecraft 1.21+ Paper/Purpur 服务器带来 RPG 化的装备、附魔、BOSS 战斗与饮食系统。

## 功能一览

- **20 种自定义附魔** —— 基于 PDC 独立存储，不与原版附魔冲突
- **强化石系统** —— 拖动强化石到装备上提升属性
- **魔法球抽奖** —— 经验值兑换，右键随机抽取附魔书
- **10 件魔法武器** —— 每件拥有独特的右键技能和战斗机制
- **食物与药品** —— 回春散（4 品级）、止血绷带、压缩饼干、肉干、甜浆果派、酒桶、腐肉干
- **5 个 BOSS** —— 急冻树、爆炎树、史莱姆王、僵尸巨人、小僵尸 Double，含元素反应机制
- **公海世界** —— 自定义地图 + 宝藏抽奖
- **GUI 菜单** —— 向导书一键打开，支持合成配方查询
- **玩家设置** —— 附魔通知开关、管理员模式

## 环境要求

| 项目 | 要求 |
|------|------|
| 服务端 | Paper / Purpur 1.21+ |
| Java | 21+ |
| 前置插件 | 无 |

## 快速开始

1. 下载 `ArmsorPlus.jar` 放入 `plugins/` 目录
2. 重启服务端
3. 用圆石合成**高级附魔向导书**，右键打开主菜单
4. OP 玩家可使用 `/ArmsorPlus help` 查看管理命令

## 自定义附魔

所有附魔通过 PDC 存储，将附魔书**拖动到装备上**即可应用，不占用原版附魔槽位。

### 装备附魔

| 附魔 | 槽位 | 效果 |
|------|------|------|
| 闪避 | 靴子 | 概率闪避攻击（PvP 15%/级，PvE 20%/级） |
| 影避 | 靴子 | 概率闪避**所有类型**伤害（6%/级） |
| 涟漪 | 靴子 | 受击回复生命值（每级 +1 HP） |
| 格挡 | 头盔 | 按伤害比例减免（>120 减 75%，>80 减 60%，其余 40%） |
| 生命提升 | 胸甲 | 每级 +5 最大生命值 |
| 涤魂 | 胸甲 | 周期性免疫魔法/中毒/凋零/龙息伤害（冷却 6-等级 秒） |
| 复仇 | 胸甲 | 20%/级概率反弹 50% 伤害 |
| 幸存 | 护腿 | 致命伤时 10%/级概率复活，满血满饱食度 |
| 不灭 | 任意 | **仅指令获取**，受到致命伤时免疫死亡并回满状态 |

## 魔法球

使用经验值在菜单商店中兑换，右键随机抽取附魔书。

| 等级 | 需求经验 | 保底层数 |
|------|----------|----------|
| 寻常 | 30 级 | 1 层 |
| 稀罕 | 50 级 | 2 层 |
| 史诗 | 70 级 | 3 层 |
| 传奇 | 150 级 | 4 层 |

每层独立抽选，10% 概率获得对应附魔书（随机等级）。

## BOSS 系统

在主菜单 → BOSS 清单中召唤，**需先进入 BOSS 世界**。

| BOSS | 生命值 | 特性 |
|------|--------|------|
| 急冻树 | 750 | 冰元素 BOSS，树形结构（躯干+核心），火/雷元素触发双倍伤害 |
| 爆炎树 | 750 | 火元素 BOSS，树形结构（躯干+核心），雷/冰元素触发双倍伤害 |
| 史莱姆王 | 750 | 巨型史莱姆手持满级重锤，跳跃粉碎攻击，半血分裂激怒 |
| 僵尸巨人 | 1500 | 原版巨人 + 僵尸 AI，攻击力 80，命中附带缓慢与击退 |
| 小僵尸 Double | 600×2 | 两只保护 IV 下界合金套小僵尸（装备不可掉落），一矛一剑 |

- 攻击**躯干部位**：3 倍武器伤害

## 公海世界（测试版）

独立世界地图，含宝藏抽奖与守护者挑战。

**config.yml 配置项：**

```yaml
SpawnOpenSea: false          # 是否启用公海世界
AutoResetOpenSeaMap: false   # 每次重启自动重置地图
OpenSeaName: "OpenSea"       # 世界文件夹名
MapZipName: "OpenSea.zip"    # 地图压缩包名
```

## 指令参考

需要 `ArmsorPlus.op` 权限（默认 OP）。

| 指令 | 说明 |
|------|------|
| `/ArmsorPlus help` | 查看帮助 |
| `/ArmsorPlus info` | 插件信息 |
| `/ArmsorPlus guide` | 获得高级附魔向导书 |
