ArmsorPlus - Minecraft 高级附魔与装备系统

为您的 Minecraft 服务器带来革命性的装备与附魔体验

🔮 概述
ArmsorPlus 是一款创新的 Minecraft 插件，它将 RPG 元素深度融入原版游戏中，提供超过 ​​30 种独特的高级附魔​​和​​定制武器装备系统​​。无论您是服务器管理员寻求增强玩家体验，还是玩家渴望更丰富的战斗系统，ArmsorPlus 都是您的完美选择。

✨ 核心功能
🛡️ 革命性附魔系统
•
​​20+ 独特附魔​​：从凋零诅咒到幸存意志，每种附魔都有独特机制

•
​​动态效果​​：视觉粒子效果与音效反馈增强游戏沉浸感

•
​​附魔协同​​：组合不同附魔产生连锁反应

•
​​等级系统​​：可升级的附魔

⚔️ 定制装备系统
•
​​传奇武器​​：带有特殊能力的独特武器

•
​​强化护甲​​：提供额外属性和技能的特殊护甲

•
​​可升级装备​​：通过使用提升装备等级和能力

🔧 高级系统

•
​​附魔抽取​​：从装备中提取附魔制作成书

•
​​附魔融合​​：组合多个低级附魔创建强大新效果

📦 安装指南
要求
•
Minecraft 服务器 1.20

•
Java 17+

•
推荐使用 PaperMC 及其分支

安装步骤
1.
下载最新版 ArmsorPlus.jar

2.
将文件放入服务器的 plugins/目录

3.
重启服务器

5.
插件将自动生成配置文件
